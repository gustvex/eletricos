# Imagens do site

Coloque aqui as fotos reais da oficina. Enquanto não existirem, o site usa
tipografia e formas — nenhuma imagem é obrigatória para o site funcionar.

Arquivos que valem a pena adicionar:

| Arquivo | Uso | Tamanho sugerido |
| --- | --- | --- |
| `og-cover.jpg` | Miniatura ao compartilhar o link no WhatsApp/Instagram | 1200×630 |
| `apple-touch-icon.png` | Ícone ao salvar o site na tela inicial do celular | 180×180 |
| `oficina-1.jpg` … | Fotos de bancada, antes/depois, equipe | 1200px de largura |

Dicas rápidas:

- Foto de bancada real converte mais que foto de banco de imagens.
- Exporte em WebP quando possível (`cwebp -q 80 foto.jpg -o foto.webp`).
- Registre a autorização do cliente antes de publicar foto do equipamento dele.
